# Yu's user story

## 1. Description
### Story A: Detailed Task Content
**As a** student,  
**I want** to provide detailed descriptions for my tasks,  
**so that** I can clearly understand the specific requirements and steps of each assignment.

### Story B: Task Authorship Visibility
**As a** team member,  
**I want** to see which classmate created or last modified a task,  
**so that** I know who to contact for further clarification or collaboration.

---

## 2. Acceptance Criteria
- [ ] **AC 1:** The "Create Task" page includes separate input fields for Title and Content.
- [ ] **AC 2:** After saving a task, the system automatically associates and displays the currently logged-in user as the Author.
- [ ] **AC 3:** The task list page allows users to see both the title and the author at a glance.

---

## 3. Scenario-based AC
**Given** I am logged into the Task Tracker and have navigated to the task list page.  
**When** I view a task created by a teammate.  
**Then** I should be able to clearly see the task descriptions their name displayed below the task title.
